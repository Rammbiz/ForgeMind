# Кришталевий Ривок (Crystal Rush)

Вертикальний раннер з армією для Android (Godot 4.7, рендерер Compatibility). Герої — ті самі,
що й у «Кришталевому Бастіоні»: лис-спідстер Блискавка і кам'яний вартовий Громило
(моделі з Meshy, скелет і анімації кодом).

## Як грати

- Герой веде армію довгим кам'яним мостом над морем. Свайп або дотик ліворуч/праворуч
  обирає доріжку.
- Плитки «+1» додають по воїну, сині ворота «+N» і «×2/×3» збільшують армію, червоні «−N» забирають.
- Червоні загони орди б'ються з армією один на один. Дерев'яні барикади коштують по воїну
  за кожне очко міцності.
- Герой сам б'є все, що попереду на його доріжці: Блискавка — часто й здалеку, Громило — рідше,
  але по натовпу. Ульта заряджається від нових воїнів і перемог: «Громовий вихор» б'є
  блискавками всіх попереду, «Смарагдовий розлом» пускає хвилі кристалічних шипів.
- У кінці фортеця з числом на брамі: армія кидається на неї, а якщо воїнів забракне, герой
  має 5 секунд, щоб добити браму сам.
- За перемоги — монети на покращення: більше воїнів на старті та швидші атаки героя.

## Структура

```
scripts/main.gd          перемикання меню ↔ забіг
scripts/autoload/        збереження, локалізація (uk/en), звук
scripts/core/            баланс, моделі (воїни, ворота, барикади, фортеця), герої, ефекти, матеріали
scripts/run/             забіг: міст і море, генератор рівнів, натовпи (MultiMesh), герой, логіка
scripts/ui/              меню, HUD, кнопки, іконки
scripts/dev/             бот, автотест балансу, скріншоти
tools/                   текстури (бруківка, плитка «+1», шум для моря), іконки, збірка APK
```

## Інструменти розробника

```bash
# Бот проходить рівні на прискоренні (skill < 1 — інколи помиляється)
godot --headless --path crystal-rush --fixed-fps 30 -- --autotest --level=1 --levels=5 --hero=titan --skill=0.85
# Скріншот (потрібен GL): меню або забіг через N секунд гри
xvfb-run -a godot --path crystal-rush --rendering-driver opengl3 --resolution 540x960 -- --shot=/tmp/s.png --level=2 --play=10
# Текстури та іконки
python3 crystal-rush/tools/gen_textures.py
```
